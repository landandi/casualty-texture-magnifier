

# Casualty Texture Magnifier

캐주얼티 스킨을 조립된 캐릭터로 보면서 편집하는 Windows용 뷰어입니다.  
A Windows tool for previewing and editing assembled Casualty character skins.

## 한국어

캐릭터 부위에 마우스를 올리면 **어떤 PNG를 수정해야 하는지** 바로 확인할 수 있어요. 부위를 선택해 클립 스튜디오 페인트나 Aseprite에서 편집용 복사본을 열고, 같은 PNG에 저장하면 조립 미리보기가 자동으로 갱신됩니다.

1. ZIP을 풀고 `CasualtyTextureMagnifier.exe`를 실행하세요. 별도 설치는 필요 없어요.
2. **텍스처 폴더 열기**에서 `CustomSprites` 또는 `Body` 폴더가 들어 있는 개별 스킨 팩을 선택하세요.
3. **포즈 변경** 모드에서 팔·다리·꼬리를 끌어 자세를 만들거나, **인형 흔들기**와 **던지기** 모드로 움직임을 확인하세요.

표정과 걷기·공격 등의 미리보기 모션도 선택할 수 있어요. 앱에서 **한국어 / English**를 전환할 수 있습니다.

게임과 스킨 텍스처는 포함되지 않습니다. 모션은 편집용 미리보기이며 게임의 공식 애니메이션과는 다릅니다.

## English

Hover over a body part to see **which PNG to edit**. Select a part to open a working copy in Clip Studio Paint or Aseprite. Save to the same PNG and the assembled preview updates automatically.

1. Extract the ZIP and run `CasualtyTextureMagnifier.exe`. No installation is required.
2. Select **Open textures** and choose your `CustomSprites` folder or an individual skin pack containing a `Body` folder.
3. Use **Pose edit** to pose the arms, legs, and tail, or switch to **Ragdoll grab** or **Throw mode** to preview movement.

You can also change expressions, preview motions such as walking and attacking, and switch the interface between **Korean and English**.

The game and its textures are not included. Preview motions are made for editing and are not official game animations.
